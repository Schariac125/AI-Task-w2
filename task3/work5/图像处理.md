### Numpy.stack:

就是一个叠叠乐工具，这东西会按照维度把你给的数组叠起来，就像下面这个样子

```python
a = np.array([1, 2])
b = np.array([3, 4])

# 默认 axis=0 (纵向叠，变成 2 行)
s0 = np.stack((a, b), axis=0) 
# 结果: [[1, 2], [3, 4]] (形状变为 2, 2)

# axis=1 (横向对齐叠，变成 2 列)
s1 = np.stack((a, b), axis=1)
# 结果: [[1, 3], [2, 4]]
```

在这一题里面的实际应用就是去把原本生成的那个二维数组改成一个三维的图像表达，具体是这么干的

```python
color_image=np.stack([grayscale_image]*3,axis=2)
```

这里让axis等于2其实是在告诉函数我这个要怎么叠，等于2就代表着跟它讲，这个地方需要开辟一个新的维度去叠它。如果是0和1，叠放的方式就会发生改变，直观一点说其实就是，因为我们要的3在最后面那个，索引应该是2，所以才等2。

### Numpy.clip:

这个函数是用来给矩阵中的值做限制的，在我们这一题里面是这样子用的

```python
color_image=np.clip(color_image,0,255)
```

这个是什么意思，就是说把这一个矩阵里面的所有元素都做一个限定值，如果比0小，那么全部等于0，比255大，全部等于255

其他用法也是同理了

### Numpy.linspace:

这个函数用来生成一个渐变的序列，默认返回的就是一个一维的数组，所以做有些操作之前要记得检查一下

```python
fade_in=np.linspace(0,1,20)[None,:,None]
```

第一个参数和第二个参数代表着返回的数组里面包含数字的区间是什么，第三个参数则代表着需要多长，后面的那个东西其实是我把这个数组变成三维的
